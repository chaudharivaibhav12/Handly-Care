## Decision
At the 2 PM detector checkpoint: stay with "anything" mode (DEC-002), and replace the Viam segmenter as the
object finder with our own height map. Pipeline: the full point cloud → world → a 5 mm grid → fit the (tilted)
table plane → cells sticking up ≥ 8 mm → connected blobs → size, height and color per blob.

## Reason
EXP-002: positions from the segmenter are steady (≤ 8 mm), but it returns object EDGES (2 cm flying-pixel
columns), not the flat tops. So a flat object was missed (blue square 0/3) and footprints were 30-60% too small.
A height map uses every point, so it sees flat tops and true footprints. The full cloud is 921,600 points
(1 per pixel, meters, with RGB) and arrives in 1.3 s, so it's affordable.
Vaibhav chose this over going straight to M3 with undersized objects, or falling back to the shape finder.
